## Installation

### CLI

```bash
npx shadcn@latest add @kombase/form-pick
```

### Manual

<Steps>
<Step>
#### Install Prerequisites

Ensure you have installed the `form`, `label`, and `radio-group` components into your project:

```bash
npx shadcn@latest add @kombase/form @kombase/label @kombase/radio-group
```
</Step>

<Step>
#### Install Dependencies

```bash
pnpm add react-hook-form @hookform/resolvers zod
```
</Step>

<Step>
#### Copy Source Code

Copy the source code from `registry/form/form-pick.tsx` into your project at `@/components/form/form-pick.tsx`.

Alternatively, fetch raw code from:
`https://kombase.komerce.id/r/form-pick.json`
</Step>
</Steps>

### Custom Render Slot

Override the default card using `renderOption`:

```tsx
<FormPick
  control={form.control}
  name="gateway"
  options={GATEWAYS}
  renderOption={(opt, isSelected) => (
    <div
      className={cn("p-4 border rounded-lg", isSelected && "border-primary")}
    >
      {opt.label}
    </div>
  )}
/>
```
