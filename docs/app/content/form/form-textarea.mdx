## Installation

### CLI

```bash
npx shadcn@latest add @kombase/form-textarea
```

### Manual

<Steps>
<Step>
#### Install Prerequisites

Ensure you have installed the `form`, `label`, and `textarea` components into your project:

```bash
npx shadcn@latest add @kombase/form @kombase/label @kombase/textarea
```
</Step>

<Step>
#### Install Dependencies

```bash
pnpm add react-hook-form @hookform/resolvers zod
```
</Step>

<Step>
#### Copy Source Code

Copy the source code from `registry/form/form-textarea.tsx` into your project at `@/components/form/form-textarea.tsx`.

Alternatively, fetch raw code from:
`https://kombase.komerce.id/r/form-textarea.json`
</Step>
</Steps>
