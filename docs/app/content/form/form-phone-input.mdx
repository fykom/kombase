## Installation

### CLI

```bash
npx shadcn@latest add @kombase/form-phone-input
```

### Manual

<Steps>
<Step>
#### Install Prerequisites

Ensure you have installed the `form`, `label`, and `phone-input` components into your project:

```bash
npx shadcn@latest add @kombase/form @kombase/label @kombase/phone-input
```
</Step>

<Step>
#### Install Dependencies

```bash
pnpm add react-hook-form @hookform/resolvers zod
```
</Step>

<Step>
#### Copy Source Code

Copy the source code from `registry/form/form-phone-input.tsx` into your project at `@/components/form/form-phone-input.tsx`.

Alternatively, fetch raw code from:
`https://kombase.komerce.id/r/form-phone-input.json`
</Step>
</Steps>
