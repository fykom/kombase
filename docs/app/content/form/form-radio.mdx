## Installation

### CLI

```bash
npx shadcn@latest add @kombase/form-radio
```

### Manual

<Steps>
<Step>
#### Install Prerequisites

Ensure you have installed the `form`, `label`, and `radio-group` components into your project:

```bash
npx shadcn@latest add @kombase/form @kombase/label @kombase/radio-group
```
</Step>

<Step>
#### Install Dependencies

```bash
pnpm add react-hook-form @hookform/resolvers zod
```
</Step>

<Step>
#### Copy Source Code

Copy the source code from `registry/form/form-radio.tsx` into your project at `@/components/form/form-radio.tsx`.

Alternatively, fetch raw code from:
`https://kombase.komerce.id/r/form-radio.json`
</Step>
</Steps>
