## Installation

### CLI

```bash
npx shadcn@latest add @kombase/form-search-select
```

### Manual

<Steps>
<Step>
#### Install Prerequisites

Ensure you have installed the `combobox`, `form`, and `label` components into your project:

```bash
npx shadcn@latest add @kombase/combobox @kombase/form @kombase/label
```
</Step>

<Step>
#### Install Dependencies

```bash
pnpm add react-hook-form @hookform/resolvers zod
```
</Step>

<Step>
#### Copy Source Code

Copy the source code from `registry/form/form-search-select.tsx` into your project at `@/components/form/form-search-select.tsx`.

Alternatively, fetch raw code from:
`https://kombase.komerce.id/r/form-search-select.json`
</Step>
</Steps>
