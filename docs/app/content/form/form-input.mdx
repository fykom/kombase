## Installation

### CLI

```bash
npx shadcn@latest add @kombase/form-input
```

### Manual

<Steps>
<Step>
#### Install Prerequisites

Ensure you have installed the `form`, `input`, and `label` components into your project:

```bash
npx shadcn@latest add @kombase/form @kombase/input @kombase/label
```
</Step>

<Step>
#### Install Dependencies

```bash
pnpm add react-hook-form @hookform/resolvers zod
```
</Step>

<Step>
#### Copy Source Code

Copy the source code from `registry/form/form-input.tsx` into your project at `@/components/form/form-input.tsx`.

Alternatively, fetch raw code from:
`https://kombase.komerce.id/r/form-input.json`
</Step>
</Steps>
