## Installation

### CLI

```bash
npx shadcn@latest add @kombase/form-password
```

### Manual

<Steps>
<Step>
#### Install Prerequisites

Ensure you have installed the `form`, `label`, and `password-input` components into your project:

```bash
npx shadcn@latest add @kombase/form @kombase/label @kombase/password-input
```
</Step>

<Step>
#### Install Dependencies

```bash
pnpm add react-hook-form @hookform/resolvers zod lucide-react
```
</Step>

<Step>
#### Copy Source Code

Copy the source code from `registry/form/form-password.tsx` into your project at `@/components/form/form-password.tsx`.

Alternatively, fetch raw code from:
`https://kombase.komerce.id/r/form-password.json`
</Step>
</Steps>
