## Installation

### CLI

```bash
npx shadcn@latest add @kombase/form-input-group
```

### Manual

<Steps>
<Step>
#### Install Prerequisites

Ensure you have installed the `form`, `input-group`, and `label` components into your project:

```bash
npx shadcn@latest add @kombase/form @kombase/input-group @kombase/label
```
</Step>

<Step>
#### Install Dependencies

```bash
pnpm add react-hook-form @hookform/resolvers zod
```
</Step>

<Step>
#### Copy Source Code

Copy the source code from `registry/form/form-input-group.tsx` into your project at `@/components/form/form-input-group.tsx`.

Alternatively, fetch raw code from:
`https://kombase.komerce.id/r/form-input-group.json`
</Step>
</Steps>

### Addon Examples

**Text Addon:**

```tsx
<FormInputGroup
  control={form.control}
  name="price"
  addon="USD"
  inputGroupProps={{ type: "number" }}
/>
```

**Compound Addon:**

```tsx
<FormInputGroup
  control={form.control}
  name="short_url"
  addon={
    <>
      <GlobeIcon className="w-4 h-4 mr-2" /> ifx.li/
    </>
  }
/>
```
