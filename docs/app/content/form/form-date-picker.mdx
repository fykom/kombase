## Installation

### CLI

```bash
npx shadcn@latest add @kombase/form-date-picker
```

### Manual

<Steps>
<Step>
#### Install Prerequisites

Ensure you have installed the `calendar`, `form`, `label`, and `popover` components into your project:

```bash
npx shadcn@latest add @kombase/calendar @kombase/form @kombase/label @kombase/popover
```
</Step>

<Step>
#### Install Dependencies

```bash
pnpm add react-hook-form @hookform/resolvers zod dayjs lucide-react
```
</Step>

<Step>
#### Copy Source Code

Copy the source code from `registry/form/form-date-picker.tsx` into your project at `@/components/form/form-date-picker.tsx`.

Alternatively, fetch raw code from:
`https://kombase.komerce.id/r/form-date-picker.json`
</Step>
</Steps>
