## Installation

### CLI

```bash
npx shadcn@latest add @kombase/rating
```

### Manual

<Steps>
<Step>
#### Install Prerequisites

Ensure you have installed the `visually-hidden-input` component into your project:

```bash
npx shadcn@latest add @kombase/visually-hidden-input
```
</Step>

<Step>
#### Install Dependencies

```bash
pnpm add @radix-ui/react-direction @radix-ui/react-slot lucide-react
```
</Step>

<Step>
#### Copy Source Code

Copy the source code from `registry/components/rating.tsx` into your project at `@/components/rating.tsx`.

Alternatively, fetch raw code from:
`https://kombase.komerce.id/r/rating.json`
</Step>
</Steps>


## Components Layout

```tsx
import { Rating, RatingItem } from "@/components/rating";

export default function RatingDemo() {
  return (
    <Rating defaultValue={3}>
      <RatingItem />
      <RatingItem />
      <RatingItem />
      <RatingItem />
      <RatingItem />
    </Rating>
  );
}
```
