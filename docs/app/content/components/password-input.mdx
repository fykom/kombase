## Installation

### CLI

```bash
npx shadcn@latest add @kombase/password-input
```

### Manual

<Steps>
<Step>
#### Install Prerequisites

Ensure you have installed the `button` UI component into your project:

```bash
npx shadcn@latest add @kombase/button
```
</Step>

<Step>
#### Install Dependencies

```bash
pnpm add lucide-react
```
</Step>

<Step>
#### Copy Source Code

Copy the source code from `registry/components/password-input.tsx` into your project at `@/components/password-input.tsx`.

Alternatively, fetch raw code from:
`https://kombase.komerce.id/r/password-input.json`
</Step>
</Steps>
