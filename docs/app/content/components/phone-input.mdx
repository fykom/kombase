## Installation

### CLI

```bash
npx shadcn@latest add @kombase/phone-input
```

### Manual

<Steps>
<Step>
#### Install Prerequisites

Ensure you have installed `command`, `input`, and `popover` components in your project:

```bash
npx shadcn@latest add @kombase/command @kombase/input @kombase/popover
```
</Step>

<Step>
#### Copy Source Code

Copy the source code from `registry/components/phone-input.tsx` into your project at `@/components/phone-input.tsx`.

Alternatively, fetch raw code from:
`https://kombase.komerce.id/r/phone-input.json`
</Step>
</Steps>
