### Addon Examples

**Text Addon:**

```tsx
<FormInputGroup
  control={form.control}
  name="price"
  addon="USD"
  inputGroupProps={{ type: "number" }}
/>
```

**Compound Addon:**

```tsx
<FormInputGroup
  control={form.control}
  name="short_url"
  addon={
    <>
      <GlobeIcon className="w-4 h-4 mr-2" /> ifx.li/
    </>
  }
/>
```
