## Installation

### CLI

```bash
npx shadcn@latest add @kombase/avatar-group
```

### Manual

<Steps>
<Step>
#### Install Prerequisites

Ensure you have installed the `avatar` UI component into your project:

```bash
npx shadcn@latest add @kombase/avatar
```
</Step>

<Step>
#### Install Dependencies

```bash
pnpm add @radix-ui/react-avatar @radix-ui/react-slot class-variance-authority
```
</Step>

<Step>
#### Copy Source Code

Copy the source code from `registry/components/avatar-group.tsx` into your project at `@/components/avatar-group.tsx`.

Alternatively, fetch raw code from:
`https://kombase.komerce.id/r/avatar-group.json`
</Step>
</Steps>
